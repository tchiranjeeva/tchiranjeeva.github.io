A custom-shaped upgrade PCB soldering directly onto an existing host board via castellated holes, adding EV Control Pilot (CP) PWM generation, ADC feedback, and RS485.

<!--more-->

A custom shaped add-on PCB designed to upgrade the hardware of an existing board. Instead of redesigning the main board, the add-on solders directly onto its existing pins through castellated holes, so the upgrade takes only minutes.

The add-on provides the control pilot (CP) function for EV charging. It generates the PWM control pilot signal and measures the CP voltage level through an ADC, so the controller can detect the vehicle's state and signal the available charging current. An isolated power stage supplies the positive and negative rails needed by the CP circuit, and an RS485 interface and a thermistor input add communication and temperature sensing. A header connects the board to the host controller. The outline is shaped to fit around the parts and connectors of the existing hardware.

### Key Features

- **Direct castellation soldering** onto existing host hardware without board redesign
- **J1772 Control Pilot (CP) PWM generator** and precision ADC measurement circuit
- **Isolated dual-rail power supply** (+12V / -12V) for bidirectional CP signal generation
- **RS485 serial communications** and NTC thermistor thermal monitoring
- **Custom mechanical outline** precision-routed to clear existing host components
